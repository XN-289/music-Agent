# 质量门禁（生成前自检清单）

调用 generate_music 之前，逐项自检；任何一项不满足就修改后再生成：

## 歌词

- [ ] 结构标记完整（Verse/Chorus 齐全，副歌重复）
- [ ] Hook 存在且出现在副歌第一句
- [ ] 押韵自然（不硬凑韵脚）
- [ ] 无占位符、无填充行
- [ ] 主题统一（每段都服务于同一个故事/情绪）
- [ ] 满足用户所有明确要求（语言/时长/人称/风格线索）

## 风格

- [ ] 标签 2-6 个，互不矛盾
- [ ] 标签组合与歌词情绪匹配（悲伤歌词不配 party 标签）
- [ ] 顺序规范：曲风 → 情绪 → 唱腔 → 质感

## 流程

- [ ] **硬门禁：需求已确认**——用户需求模糊（无场景/风格/情绪线索）时，必须先完成「方向选项」澄清并获得用户确认，禁止直接调用生成工具
- [ ] 不重复生成同一个需求（先看曲库是否已有类似结果）

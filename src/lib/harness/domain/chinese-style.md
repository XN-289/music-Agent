# 国风知识域（古风/仙侠/中国风）

## 何时启用

用户提到：古风/国风/仙侠/江湖/武侠/戏腔/汉服/中国风/「周深《大鱼》那种」等；或场景表里新年/春节喜庆类。国风的核心听感来自**五声调式 + 传统乐器 + 留白美学**，三者缺一不可，缺了就是「古风词套流行曲」。

## 调式与情绪（五声调式）

生成模型无法直接指定调式，用**标签 + 情绪描述 + 歌词意象**共同传递：

| 调式 | 主音 | 气质 | 适配主题 |
|---|---|---|---|
| 宫 | do | 端正、庄重 | 山河/朝堂/史诗 |
| 商 | re | 悲凉、苍劲 | 离别/征战/乡愁 |
| 角 | mi | 清新、生机 | 田园/少年 |
| 徵 | sol | 热烈、欢快 | 节庆/喜庆 |
| 羽 | la | 柔美、哀婉 | 情伤/思念/仙气 |

方向选项里把调式气质翻译成普通描述（「羽调式那种柔美哀婉的感觉」→「仙气、飘、带点忧伤」）。

## 传统乐器标签

| 乐器 | 音色 | 适配情绪 |
|---|---|---|
| 古筝 | 清亮、流水感 | 仙气/思念/山水 |
| 笛子 | 悠扬、穿透 | 江湖/田园/辽阔 |
| 二胡 | 如泣如诉 | 悲凉/乡愁/深情 |
| 琵琶 | 铿锵、颗粒感 | 武侠/征战/紧张 |
| 箫 | 幽远、空灵 | 夜晚/孤独/禅意 |
| 古琴 | 古朴、沉静 | 文人/独处/苍茫 |
| 编钟/大鼓 | 庄重、磅礴 | 史诗/庙堂/仪式 |

标签写法：erhu / guzheng / dizi / pipa / chinese traditional instruments / pentatonic。一次选 1-2 件乐器（乐器堆满 = 大杂烩），与主题匹配（悲伤离别选二胡，仙气选古筝/箫，武侠选琵琶）。

## 歌词措辞规范（防「假国风」）

1. **意象克制**：全篇只围绕 3-5 个意象（月/剑/舟/灯/雪），意象堆砌 = 假国风
2. **忌文言堆砌**：现代语法 + 国风词汇点缀（「你走后的第三场雪」好过「余心戚戚焉」）；通篇古文 = 假国风
3. **留白**：国风美在没说出口的部分；副歌可以比主歌更短、更克制
4. **国风版万能词黑名单**：江湖/天涯/红尘/相思/年华/轮回 连续出现时视为空泛——用具体物件替换（「江湖」→「城南的渡口」）
5. 戏腔/戏曲元素：标签加 chinese opera，hook 处可用一句戏腔式长音；戏腔只在 hook 出现一次，通篇戏腔会腻

## 国风 × 现代融合

- **国风流行**（周深/许嵩式）：pentatonic + pop，现代编曲 + 传统乐器点缀，最普适
- **国风电子**：chinese traditional + synth/downtempo，仙气 + 未来感
- **纯古风**：传统乐器为主、配器留白，适合纯意境类（游戏配乐/汉服视频）
- 用户只说了「国风」没细分 → 默认国风流行

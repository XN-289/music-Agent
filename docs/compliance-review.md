# 玩法层合规评审：仿写热歌 / 音色克隆（P2-4）

> 状态：待拍板。原则：**先评审再实现**——这两个玩法是海绵音乐的核心功能，但字节做得了不等于我们做得了：字节有曲库授权、法务团队和平台资质，我们都没有。

## 1. 仿写热门歌曲

### 1.1 风险拆解

| 风险 | 具体内容 | 等级 |
|---|---|---|
| 词曲著作权 | 仿写若与热歌旋律实质相似（编曲/和声进行/记忆点旋律），构成侵权；「仿写」在中国司法实践中没有避风港 | 🔴 高 |
| 歌词著作权 | 歌词高度相似（同韵脚、同意象、同句式）也有风险，但低于旋律 | 🟡 中 |
| 平台责任 | 我们是服务提供者：接到通知未处理将承担连带责任；「明知/应知」可被推定侵权 | 🔴 高 |
| 商标/艺人形象 | 用户输入「仿写周杰伦的晴天」涉及艺人姓名肖像与作品关联性 | 🟡 中 |

### 1.2 海绵为什么能做

- 字节与主要版权方（腾讯音乐、网易云音乐等）有曲库授权合作
- 内部法务 + 平台级投诉处理体系 + 生成内容自动查重过滤
- 大概率做了「仿写=风格仿作」的语义引导，规避「复刻旋律」

### 1.3 可行方案（降低到可接受风险）

1. **语义引导替代**：功能名用「风格创作」而非「仿写」；用户输入歌名时，Agent 提取**风格标签**（曲风/情绪/唱法/结构特征）而非旋律——输出「《晴天》风格的前奏式流行摇滚」，不做旋律级仿作
2. **歌词改写查重**：AI 改词时做相似度约束（提示词要求原创意象，禁止照搬原词）
3. **投诉处理通道**：产品内「举报侵权」入口 + 下架流程（24h 响应），满足避风港条件
4. **上线节奏**：第一版不做「输入歌名直接仿写」入口，只做「风格标签仿作」；收集用户反馈后再评估

**结论：可做，但必须按 1.3 的语义边界实现，且投诉通道与下架流程先于功能上线。**

## 2. 音色克隆

### 2.1 风险拆解

| 风险 | 具体内容 | 等级 |
|---|---|---|
| 声音权益 | 《民法典》第 1023 条：对自然人声音的保护参照肖像权——未经本人授权克隆他人声音构成侵权 | 🔴 高 |
| 深度合成规定 | 《互联网信息服务深度合成管理规定》：提供人脸/人声等生物识别信息编辑功能需**单独授权同意**，并显著标识 | 🔴 高 |
| 诈骗滥用 | 克隆声音被用于诈骗/伪造的衍生风险，平台需留痕 | 🟡 中 |

### 2.2 行业通行做法（海绵/豆包同款）

- **只允许克隆用户自己的声音**：上传本人录音 + 读出系统生成的验证短语（活体/本人证明）
- 服务条款明示：仅限本人声音、禁止用于欺诈；违反封号
- 生成内容自动添加深度合成标识

sunoapi 的 Voice API 恰好是同一套流程：`validate`（生成验证短语）→ 用户录音上传 → `voice/generate`（verifyUrl=录音）→ `voiceId`。技术上与我们已有的 Provider 层直接衔接。

### 2.3 可行方案

1. **本人声音验证流程**：照抄行业做法（上传→验证短语→录音→生成 voiceId）
2. **条款与标识**：克隆前强制同意《声音克隆服务条款》；生成歌曲带「AI 生成」标识
3. **留痕**：voiceId 与用户绑定，支持投诉封禁

**结论：可做，流程必须含本人验证 + 条款同意 + 生成标识。技术通道（sunoapi Voice API）已就绪。**

## 3. 生成式 AI 服务合规（两个玩法之外的基础项）

| 事项 | 要求 | 状态 |
|---|---|---|
| 生成式 AI 备案 | 《生成式人工智能服务管理暂行办法》：面向境内公众提供服务需向网信办备案 | ❌ 待办（公开上线前） |
| 深度合成标识 | 生成内容显著标识（页面标识 + 元数据） | ❌ 待办 |
| 算法备案 | 具有舆论属性或社会动员能力的算法需备案 | ⚠️ 待评估 |
| 内容审核 | 敏感词过滤、违规内容拦截 | ✅ 部分（sunoapi SENSITIVE_WORD_ERROR + Agent 修复闭环） |
| ICP 备案 | 域名 + 服务器（若境内服务器） | ❌ 待办 |
| 投诉通道 | 侵权举报 + 24h 处理承诺 | ❌ 待办（先于仿写功能） |

## 4. 建议节奏

| 阶段 | 范围 | 合规要求 |
|---|---|---|
| **MVP 内测**（当前→key 到位后） | 对话创作 + 迭代闭环 | 低：内测用户、不公开传播 |
| **灰度**（P2-4 玩法层） | + 风格创作（仿写的安全版） | 中：投诉通道 + 内容审核 + 标识 |
| **公开上线**（P3） | + 音色克隆 + 社区 | 高：备案 + 深度合成标识 + 音色克隆本人验证 + ICP |

**一句话结论**：仿写→做成「风格创作」+ 投诉通道先行；音色克隆→本人验证流程 + 条款 + 标识；备案等资质在公开上线前启动（周期数月，需提前排期）。

# Music Agent 设计系统（2026-08-20）

沉淀产品 UI 的设计决策。改 UI 前先读这里；迭代后更新这里。

## 原则（用户硬指令）

1. **shadcn**：组件一律走 shadcn（Radix + Tailwind），不手写
2. **少字**：无描述性文本元素；界面文字只保留动作与状态
3. **浅色 + 绿 accent**：禁蓝紫暗色、禁 Claude 风（米白+暖橙+serif）
4. **扁平克制**：圆角 ≤ rounded-lg，胶囊只用于播放/标签；细边线代替嵌套卡片；阴影最多 shadow-sm；无目的嵌套边框一律去掉
5. **是产品不是落地页**：输入框即主角（Suno 文本主导），无 hero 营销感

## 色彩

- **背景**：`#FAFAFA`（neutral-50，冷白，非米色）
- **表面**：`#FFFFFF`，用 hairline 边线（`#E5E5E5`）区分层级，不用阴影分层
- **Accent 绿**：主 `#16A34A`（green-600），hover `#15803D`，浅底 `#DCFCE7`（green-100）——**只用于功能元素**：播放按钮、主 CTA、激活态、进度条。禁用装饰性绿色
- **文字**：主 `#18181B`（zinc-900），次 `#71717A`（zinc-500）
- **语义**：错误 `#DC2626`、警告 `#D97706`、信息 `#2563EB`（仅状态场景）
- **界面无彩色**：专辑封面/渐变封面是唯一色彩来源

## 字体

- 拉丁显示：**Space Grotesk**（几何无衬线，音乐感），用于标题、按钮、标签、风格标签徽章
- 正文中文：系统栈 `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 不用 serif（用户禁令）
- 数字/时长：tabular-nums

## 几何

- 圆角：卡片/输入 `rounded-lg`(8px)，按钮 `rounded-md`(6px)，胶囊 `rounded-full` 仅播放按钮与 chips
- 边线：`border` 1px，中性色，代替阴影与嵌套卡片
- 阴影：默认无；浮层（弹窗）最多 `shadow-sm`

## 组件规范

| 组件 | 规范 |
|---|---|
| 按钮 | 主按钮=绿实底白字；次按钮=白底边线；图标按钮=无边框幽灵 |
| 卡片（歌曲卡） | 封面渐变 + 白底 + hairline 边；hover 边线变深，不用阴影放大 |
| 对话 | 文本主导：助手消息纯文本无气泡；用户消息浅绿底（green-50）圆角 md；方向选项=白底 hairline 卡片可点击 |
| 进度 | 绿 progress + 当前阶段文案，无多余说明 |
| 播放栏 | 白底 hairline 顶边，绿播放按钮 |
| 空态 | 标题 + chips + 最近作品，无长描述 |
